# TEE platform

| Status | Owner | Needed by |
| --- | --- | --- |
| Accepted | Felix | Phase 0 |

## Context

The biggest schedule risk is TEE setup, so it is time-boxed to the first 3 hours.

## Options

EigenCompute, Phala dstack or AWS Nitro Enclaves.

## Decision

Use AWS Nitro Enclaves. A non-debug enclave runs successfully and its attestation document has been verified against the AWS root certificate and expected build measurements. The phase-0 service is available through an SSH tunnel; public HTTPS ingress remains open.
