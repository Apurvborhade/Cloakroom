# Missing EIP-712 types

| Status | Owner | Needed by |
| --- | --- | --- |
| Open | Shreyas, Pradnyesh | Phase 1 |

## Problem

Session-signed reads and `POST /intents/cancel` are used by the API but have no type in `types`.

## Proposal

Add `SessionQuery` (owner, expiry) and `CancelIntent` (owner, intentId, nonce, expiry). Reads need no owner nonce, otherwise they collide with wallet-signed nonces.
