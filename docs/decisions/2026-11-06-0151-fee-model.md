# Fee model

| Status | Owner | Needed by |
| --- | --- | --- |
| Accepted | Shreyas, Apurva | Phase 1 |

## Problem

The initial project specifications disagreed on fee semantics:
1. The early plan proposed charging a fixed fee in the input token (`tokenIn`).
2. Config comments referenced a percentage fee on the input amount.
3. The executor specification (`docs/chain-logic.md` step 7) credited "output minus the fee".
4. Withdrawal fees and gas expenditure accounting were undefined.

## Existing behavior

The executor in `services/enclave/src/executor.ts` assesses gas costs via `FEE_BOOKED` on withdrawals, but does not deduct any fee from the user's withdrawal amount. Uniswap swap execution quotes the full `amountIn` to Universal Router.

## Decision

1. **Swap protocol fee:** Assessed in basis points (`FEE_BPS`) deducted directly from the output token (`tokenOut`) upon confirmed swap execution.
   ```
   protocolFee = (amountOut * FEE_BPS) / 10000n
   netAmountOut = amountOut - protocolFee
   ```
   BigInt integer division is used (rounds towards zero, favoring the user).
   `netAmountOut` is credited to the owner's available balance in `tokenOut`.
   `protocolFee` is credited to the enclave protocol revenue ledger.
2. **Failed swaps:** If a swap reverts or fails, no protocol fee is charged. The reserved `amountIn` is returned entirely to the owner's available balance via `ledger.release(intentId)`.
3. **Withdrawals:** In the MVP, withdrawals incur zero protocol fee (`withdrawalFee = 0`). The user receives exactly the requested `amount`.
4. **Gas expenditure:** On-chain gas consumed by custody EOAs (`gasUsed * effectiveGasPrice`) is an operational expense of the liquidity pool. It is recorded to the operational fee ledger via `FEE_BOOKED`, and is strictly excluded from charging users.
5. **Replay representation:** `EXEC_SETTLED` contains `{ fee: bigint }`, and `FEE_BOOKED` contains `{ feeAmount: bigint }`, allowing deterministic replay of revenue and gas ledgers.

## Alternatives considered

- **Fee on input token:** Taking `FEE_BPS` from `amountIn` before swapping. Rejected because it complicates exact condition checks against the Uniswap quote and would require quoting an odd, fee-reduced amount.
- **Fixed gas fee on withdrawals:** Charging a flat native ETH fee for withdrawals. Deferred for MVP; keeping withdrawals zero-fee simplifies testing and frontend UX.

## Consequences

- Invariant 1 holds: physical balance covers user claims plus protocol revenue.
- The executor and ledger are aligned on output-token fee deductions.
- `EXEC_SETTLED` event carries `fee: bigint`.
